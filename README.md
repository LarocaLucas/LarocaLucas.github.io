## Stack

HTML, CSS e JavaScript puros, sem build. Fundo de partículas com three.js (CDN fixado em 0.170.0).

## Estrutura

```
index.html          página única (textos fixos)
css/style.css       estilos
js/main.js          lista de projetos, filtros e animações
js/particulas.js    anel de partículas (three.js)
img/                capturas 1280×720 (WebP) e og.png
```

## Rodar localmente

```bash
python -m http.server 8000   # abrir http://localhost:8000
```

## Publicar

GitHub Pages, automático a cada push na `main`. Ao mudar CSS/JS, suba o `?v=` no `index.html`.
